# Bao Kham Chau — GitHub Pages site

A responsive academic website with a homepage, research agenda, portrait, research-agenda page and download, consultation contact, SSRN profile, UMKC profile link, and a CV download. The site is based on the supplied academic CV and research agenda. The CV download uses the supplied version without Bao's personal email and phone number.

## Preview locally

Open `index.html` in a browser. The portrait and CV are included in `assets/`.

## Publish at `username.github.io`

1. Create a GitHub repository named exactly `YOUR-GITHUB-USERNAME.github.io`.
2. Upload the contents of this folder to the repository root.
3. In repository **Settings → Pages**, select deployment from the `main` branch and `/ (root)`.
4. GitHub Pages will publish at `https://YOUR-GITHUB-USERNAME.github.io/`.

The GitHub username determines the final URL and repository name.
